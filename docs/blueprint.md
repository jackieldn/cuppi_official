# **App Name**: MotionVerse

## Core Features:

- Homepage Showcase: Display a landing section with a welcome message, showreel image, and buttons to view the portfolio or watch the showreel.
- Featured Work Gallery: Showcase a selection of featured projects with clickable images that lead to detailed project pages.
- Showreel Player: Embed a video player for the latest showreel, prominently displayed on the homepage.
- About Me Section: Present a brief bio with an image and a button linking to a more detailed about page.
- Testimonials Carousel: Display rotating testimonials from producers with a link to a dedicated feedback page.
- MacOS Dock Navigation: Implement a MacOS-style dock menu with squircle icons for easy navigation throughout the site.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey professionalism and creativity.
- Background color: Light blue-gray (#E8EAF6) for a clean and modern look.
- Accent color: Orange (#FF9800) to highlight important elements like buttons and links.
- Body font: 'Inter' (sans-serif) for a modern, readable design.
- Headline font: 'Space Grotesk' (sans-serif) to make impactful headlines.
- Use minimalist icons with a squircle shape for the MacOS dock-style navigation.
- Employ a 20-80 split layout with a centred MacOS app dock-style menu.
- Subtle animations on hover for portfolio images and button interactions.
